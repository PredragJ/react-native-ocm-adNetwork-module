# react-native-ocm-adnetwork-module

This example demonstrates the `react-native-ocm-ad-network-module` in a simpleReact Native application. On launch the OCM SDK is initialized, a banner ad ismounted in the view hierarchy, and buttons are provided to load and showinterstitial and rewarded ads. Events emitted by the SDK are displayed onscreen for easy debugging.

## Installation


```sh
npm install react-native-ocm-adnetwork-module
```


## Usage


```js
import { multiply } from 'react-native-ocm-adnetwork-module';

// ...

const result = multiply(3, 7);
```
